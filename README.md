# Робот EMO из телефона

Милый настольный робот: «голова» — старый телефон с живыми глазами на экране,
«ноги» — тележка на ESP32 с двумя моторами.

## Что уже есть
- `index.html` — глаза робота. Открывается в браузере телефона: моргают, следят за пальцем,
- `robot-3d.html` — 3D-модель робота: детали, цены, как всё работает.
  меняют эмоции по тапу, спят с 23:00 до 7:00. Звуки, напоминание размяться, режим «тихо».
  Если открыть как обычный сайт: видит лицо через селфи-камеру, слышит голос и крик.

## План
1. Голос и мозг на ИИ (слушает, отвечает, узнаёт хозяина камерой).
2. Список покупок для тележки (ESP32, моторы, колёса).
3. Прошивка ESP32.
4. Инструкция по сборке с картинками.
